# OnboardX

Customer onboarding and KYC platform for a bank: lead capture, KYC document upload and checklist, stubbed document classification, AML/PEP screening, versioned risk-band classification, compliance-officer manual review with audited overrides, stubbed account creation, and admin reports. All code is generated by Claude Code agents (no hand-coding); synthetic data only.

## Quick Reference

**Backend:** `cd backend && .venv/Scripts/python -m pytest -x -q` | `ruff check --fix .` | `mypy src/` (venv active)
**Frontend:** `cd frontend && npm test` | `npm run lint` | `npm run typecheck`
**Full stack:** Start backend + frontend (see init.sh)

## Architecture

Strict layered architecture: Types → Config → Repository → Service → API → UI.
One-way dependencies only. See `.claude/architecture.md` for full rules.

## Code Style

- TDD mandatory: test first, then implement
- 100% meaningful coverage target, 80% floor
- Functions < 50 lines, files < 300 lines
- Static typing everywhere (zero `any`)
- See `.claude/skills/code-gen/SKILL.md` for full rules
