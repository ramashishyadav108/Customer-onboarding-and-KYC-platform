# E5-S4: Admin console dashboard shows operational reports

- **Epic:** E5 - Reports and Admin Console (Sprint 5)
- **Layer:** UI
- **Group:** L
- **depends_on:** E5-S3, E3-S5
- **Covers:** AC-10

## Description

A desktop-first admin dashboard with TAT by product, approval funnel, manual-review backlog, average time per stage and top rejection reasons, plus navigation to rules and watchlist pages.

## Acceptance Criteria

1. The dashboard renders five panels (TAT by product, approval funnel, manual-review backlog, avg time per stage, top rejection reasons) with values from the reports API.
2. Changing the product or date filter refreshes every panel using the same filter values.
3. Every chart has an equivalent data table and a text summary, and meaning is never conveyed by colour alone.
4. With no data each panel shows an explicit empty-state message instead of a blank area or error.
5. The dashboard has zero serious or critical axe-core violations at 1280 px, is fully keyboard operable, and the admin navigation links to the rules and watchlist pages; non-admin users are redirected to a forbidden page.
