# E2-S2: Missing documents or profile block case submission

- **Epic:** E2 - Document Upload and Classification Stub (Sprint 2)
- **Layer:** API
- **Group:** E
- **depends_on:** E2-S1, E1-S4
- **Covers:** AC-02, AC-04

## Description

The prospect submits the case once every mandatory checklist item has a document and the profile is complete. Otherwise submission is blocked and the gaps are listed.

## Acceptance Criteria

1. POST /api/v1/cases/{case_id}/submit with every mandatory checklist item uploaded and the profile complete returns 200 and moves the case to DOCS_SUBMITTED.
2. If any mandatory item lacks a document, submit returns 422 with code MISSING_DOCUMENTS and a missing_items array naming each absent item code; the state remains INITIATED.
3. If the profile is incomplete, submit returns 422 with code MISSING_PROFILE and the missing field names; the state remains INITIATED.
4. Submitting an already DOCS_SUBMITTED case returns 200 idempotently without a second history row; submitting a case in any later state returns 409 INVALID_STATE.
5. Successful submission appends an audit entry DOCUMENTS_SUBMITTED listing the document ids, and GET case returns an empty missing_items array afterwards.
