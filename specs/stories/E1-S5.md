# E1-S5: Document checklist is defined per product and versioned

- **Epic:** E1 - Lead Capture, Foundation and Checklist (Sprint 1)
- **Layer:** Config
- **Group:** A
- **depends_on:** []
- **Covers:** AC-02, NFR-05

## Description

Each product has a KYC document checklist. Checklists are seeded by migration, versioned, and exposed read-only. Cases pin the version that applied when they were created.

## Acceptance Criteria

1. The Savings checklist contains mandatory items ID_PROOF (accepts PAN, AADHAAR, PASSPORT), ADDRESS_PROOF (accepts AADHAAR, PASSPORT, UTILITY_BILL) and PHOTOGRAPH (accepts PHOTOGRAPH).
2. The Current checklist contains all Savings items plus mandatory BUSINESS_PROOF (accepts GST_CERTIFICATE).
3. The NRE checklist contains ADDRESS_PROOF, PHOTOGRAPH, an ID_PROOF restricted to PASSPORT, and mandatory OVERSEAS_ADDRESS_PROOF (accepts VISA).
4. GET /api/v1/products/{product}/checklist returns version and items for any authenticated user; an unknown product returns 404.
5. Checklist templates are created by append-only migrations; a new version never alters an older one, and a case created under version N continues to report version N after version N+1 is seeded.
