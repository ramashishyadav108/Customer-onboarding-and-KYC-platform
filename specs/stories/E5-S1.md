# E5-S1: Turnaround and per-stage duration metrics are computed from history

- **Epic:** E5 - Reports and Admin Console (Sprint 5)
- **Layer:** Service
- **Group:** B
- **depends_on:** E1-S4
- **Covers:** AC-10, NFR-01

## Description

Metrics derive purely from append-only state history so they cannot drift from the audit trail. All values are integer seconds.

## Acceptance Criteria

1. TAT per closed case is the seconds between its INITIATED and APPROVED or REJECTED history timestamps; TAT by product returns case count, average, minimum and maximum in whole seconds.
2. Average time per stage is the mean seconds between consecutive transitions grouped by from-state; open cases contribute only their completed stages.
3. Open cases (not APPROVED, REJECTED) are excluded from TAT aggregates.
4. All queries accept optional product and from/to UTC date filters (inclusive); an empty result returns zero counts and zero averages, not an error.
5. Averages use integer floor division; a test over a 50-case synthetic fixture matches precomputed expected values exactly and static scan finds no float in the metrics module.
