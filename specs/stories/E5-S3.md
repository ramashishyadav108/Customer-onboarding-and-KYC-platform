# E5-S3: Admin reports API serves all admin metrics

- **Epic:** E5 - Reports and Admin Console (Sprint 5)
- **Layer:** API
- **Group:** K
- **depends_on:** E5-S1, E5-S2, E1-S2
- **Covers:** AC-10, NFR-04

## Description

Thin controllers exposing the metric services to the admin role.

## Acceptance Criteria

1. GET /api/v1/admin/reports/tat, /funnel, /backlog, /time-per-stage, /rejection-reasons and /auto-approval return 200 and JSON for an admin token.
2. Each report endpoint returns 401 without a token and 403 for prospect, kyc-analyst and compliance-officer tokens.
3. Query parameters product (Savings, Current, NRE) and from/to (ISO date) are validated: an invalid product or date returns 422 naming the parameter.
4. Each report responds in under 500 ms at the 95th percentile over 1,000 synthetic cases.
5. Report responses contain no names, contact details or document content; only aggregates and case_ids.
