# E3-S5: Staff can review case evidence and manage rules in the staff UI

- **Epic:** E3 - Screening and Risk Classification (Sprint 3)
- **Layer:** UI
- **Group:** H
- **depends_on:** E3-S3, E3-S4, E2-S4
- **Covers:** AC-03, AC-05, AC-06

## Description

Desktop-first staff screens: an analyst workbench and case detail, plus admin pages for rule sets and watchlist.

## Acceptance Criteria

1. The analyst workbench lists cases with columns case_id, product, state and age, filterable by state and product and sortable by age.
2. Case detail shows each document with class, status and reason code, the screening result (hits with list type and reason code), and the risk score, band and rule version.
3. The analyst can reject a document by choosing a reason code from a select; Reject stays disabled until a reason is chosen, and the row shows REJECTED after success.
4. The admin rules page shows PUBLISHED versions with all inputs disabled and DRAFT versions editable with Publish; the watchlist page adds an entry and shows it in the list.
5. Staff pages render at 1280 px with zero serious or critical axe-core violations and are fully keyboard operable; contact values are masked by default.
